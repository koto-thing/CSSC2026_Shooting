# メインのループについて
## エントリーポイントってどこ？

* javascriptでは、C++のような`main()`関数は存在しない。
* javascriptでは、HTMLの`<script>`タグ内のコードがエントリーポイントとなる。

## cppでいうところのwhileループはどこ？

* javascriptでは、C++のような明示的なwhileループは使わない。
* javascriptでは、`requestAnimationFrame`を使った再帰呼び出しによってメインループを実現する。

## クラスは作れるの？

* javascriptでは、ES6以降で`class`構文が導入されており、クラスを作ることができる。
* メンバ変数は、`this.`が必須。
* メンバ変数の事前宣言は任意。（コンストラクタ内で定義されると勝手に宣言されたことになる）
* プライベート変数・関数は、変数名・関数名の前に`#`をつけることで定義できる。
* クラスの継承は、`extends`キーワードを使うことで可能。
* 親クラスのコンストラクタを呼び出す場合は、`super()`を使う。
* 純粋仮想関数は、親クラスで例外を投げておくといいらしい。子クラスでオーバーライドされなかった場合に例外が投げられる。
